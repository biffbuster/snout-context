# Benchmark status for Snout 0.3.1

The 0.3.1 release has one paired agent result: 140 Claude Code sessions on Sonnet over the 14-task regression fixture, −25.5% cost per solved task (95% interval −39.1% to −7.6%), all attempts passing in both arms. Its setup, limits and raw rows are in [the 0.3.1 archive](archive/0.3.1/claims.md). It has **no held-out agent score** yet; those tasks were written alongside Snout. A small [GPT-6 Sol Codex pilot](experiments/codex-gpt6-sol-2026-10-19/README.md) is recorded for diagnosis; its intervals cross zero. Historical results, reports, and methodology are preserved in [the pre-0.3.1 archive](archive/pre-0.3.1/README.md). Do not use those numbers as evidence for the current build.

Run held-out coding tasks on this Windows machine with Snout off and on, using the exact built package users install. Record the package version, commit, dirty state, bundle and harness hashes, model, machine, task IDs, every attempt, pass/fail, and cost or tokens. Compare cost per solved task and report the paired 95% interval and any task that passes off but fails on. Preserve failed attempts and infrastructure exclusions.

The 140-session Claude Code release regression is complete; its recorded API spend was $13.3121. Next, confirm the shipped hooks under live Claude Code and Codex hosts, then run a separately approved, capped held-out pilot to check feasibility and variance. A Codex off/on benchmark is a separate agent result, measured in effective tokens until billed cost is available. Rebuild derived reports from the new raw rows with `node bench/report.mjs` and cite only those files in [current claims](claims.md).
