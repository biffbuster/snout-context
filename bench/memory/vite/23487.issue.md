# Pass filenames including queries to `renderBuiltUrl` like <8.3.0 (issue #23487)

[link removed] made filenames passed to `renderBuiltUrl` not to contain the queries (and hashes). But Vinext returns URL containing queries from `renderBuiltUrl` and that causes final URL to be like `asset.svg?dpl=id?marker=value` ([link removed] it was `asset.svg?dpl=id&marker=value` as the query injection was handled by `renderBuiltUrl`).

To fix this we need to either:

- pass a new param to `renderBuiltUrl` that contains queries / hashes
- include queries / hashes in the `filename` param of `renderBuiltUrl` as before

Another thing we need to decide is whether this query handling should exist on Rolldown (/ Rollup) side, or be handled by `urlId`.
