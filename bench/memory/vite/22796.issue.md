# Highlight Or Label The Primary Network of `--host` Output URLs (issue #22796)

### Description

```
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://172.18.0.1:5173/
  ➜  Network: http://10.233.157.11:5173/
  ➜  Network: http://172.18.208.1:5173/
```

Everytime these URLs change, and everytime I need to type every single one of them on my phone browser to find the one that works. It's annoying and takes time to write and it's a bad DX.

### Suggested solution

```
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://172.18.0.1:5173/     xray_tun
  ➜  Network: http://10.233.157.11:5173/  Wi-Fi
  ➜  Network: http://172.18.208.1:5173/   vEthernet (WSL (Hyper-V firewall))
```
